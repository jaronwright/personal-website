# personal-website

Source for [jaronwright.com](https://jaronwright.com) — a small Next.js site where I keep what I've made.

## Stack

- Next.js (App Router) + React 19
- TypeScript

## Develop

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — lint
